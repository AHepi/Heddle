## derive

Before reading any implementation, write down what the authority
requires. Authority here is the map: the REQ- doc for the work under
review, plus any CON- or INV- contract it names (read_map). Cite the
clause for each expectation — the REQ number or the contract line, not
a paraphrase. Name the strongest alternative reading for anything
ambiguous, and say which reading you will hold the code to and why.

You read no code in this step. Expectations derived after seeing the
implementation are rationalizations, not expectations.

Outcome: derived.
